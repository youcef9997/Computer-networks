**🌐 HairLux LTD — Network Infrastructure Design**

**⚠️ Academic / Simulated Project**

HairLux LTD is a fictional company and the business scenario presented in this project is entirely simulated for academic purposes. No real client or production network was involved.

The project was created to demonstrate how I would analyse business requirements, design a network infrastructure, configure network devices and validate the resulting solution using Cisco Packet Tracer.

⸻

**🎯 Project Overview**

This project presents a fictional business networking scenario in which HairLux LTD is expanding across London and Manchester and requires a reliable network infrastructure for its simulated workforce.

The scenario assumes:

* 2 locations: London & Manchester
* 4 offices: 2 per location
* 50 employees
* 40 network-connected devices
* Wired and wireless connectivity
* Communication between both locations
* Dynamic IP addressing
* Secure remote administration
* Router redundancy

The entire network was designed, configured and tested in Cisco Packet Tracer as a simulation. No physical network infrastructure was deployed.

⸻

**🎓 Project Purpose**

The purpose of the project was to demonstrate practical networking skills in a controlled academic environment, including:

* Network architecture and design
* IPv4 addressing and CIDR subnetting
* DHCP configuration
* RIP v2 routing
* SSH remote administration
* Cisco HSRP redundancy
* Network connectivity testing
* Troubleshooting
* Scalability and reliability analysis

The accompanying PDF contains the full technical design, configuration process, testing evidence and evaluation.
